Step 01 / Pre-flight

Check the essentials.

Read the latest README and verify the current branch before installing anything.

Tip: start in simulator mode if supported. It separates software problems from hardware and network problems.
Step 02 / Get the code

Clone the repository.

Run these commands in a terminal. If the latest work is still on a feature branch, use that branch when cloning.

git clone --branch aura-link-v6-upload https://github.com/ayushmaurya65236-code/V6.git
cd V6
Step 03 / Environment

Prepare Python.

Use the Python version supported by the current requirements. A virtual environment avoids conflicts with other projects.

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version

Only if the repository contains requirements.txt, install it:

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Step 04 / Model & camera

Verify vision assets.

Check that the model file exists at the exact path expected by the source and that camera access is enabled.

Do not download a random model with a similar filename. Follow the model source and path documented by the project.
Step 05 / ESP32 link

Connect the hardware layer.

Use the actual firmware and communication settings in this repository; these may differ across versions.

Never power motors directly from ESP32 GPIO pins. Use the suitable driver and power arrangement.
Step 06 / Test & launch

Run one layer at a time.

Use the documented entry point instead of guessing the launch filename. Test the simulator first, then test one safe hardware action.

Diagnostics

When something fails.

Import / package error

Confirm the virtual environment is active, check Python compatibility, and install from the project's dependency manifest.

Camera / model error

Check permissions, asset paths, expected model format, and the full traceback.

ESP32 not found

Verify power, Wi-Fi, firewall rules, discovery settings, and firmware compatibility.

For debugging, record the full error, command, Python version, and whether you used simulator mode. Never publish Wi-Fi passwords or private tokens.
